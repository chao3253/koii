# 服务器购买教程（零基础版）

> 目标：买到一台能用来部署 Supabase 的轻量服务器。
> 全程大约 10 分钟，第一次买照着点就行。
> 价格会随活动变化，文档里写的是「大致范围」，以付款页面实际显示为准。

---

## 0. 先决定买哪家

| | 腾讯云轻量 | 阿里云轻量 |
|---|---|---|
| 适合谁 | 个人开发者口碑好、控制台简单 | 你域名在阿里，账号现成 |
| 价格 | 通常更便宜、活动多 | 略贵一点，但生态全 |
| 操作 | 几乎一样 | 几乎一样 |

**建议**：哪家账号现成、哪家便宜就买哪家。下面以**腾讯云**为例，阿里云的按钮名字略有不同，逻辑完全一样。

> 你的域名在阿里云，不影响买腾讯云服务器——域名解析在阿里云控制台改一下就行。

---

## 1. 注册账号 + 实名认证

1. 打开 [cloud.tencent.com](https://cloud.tencent.com)（阿里云是 [aliyun.com](https://www.aliyun.com)）
2. 右上角「注册 / 登录」，用微信或手机号注册
3. 进入「控制台」→ 按提示完成**实名认证**
   - 个人认证：身份证 + 人脸识别，几分钟
   - 不实名买不了服务器，这一步绕不开

> 💡 **为什么要实名？** 国内云厂商受监管要求，所有服务器都要绑定真实身份。
> 香港节点同样需要账号实名，但**域名不需要 ICP 备案**。

---

## 2. 找到「轻量应用服务器」

腾讯云：

1. 控制台左上角搜索框输入 **轻量**
2. 点「轻量应用服务器 Lighthouse」
3. 点「新建」或「立即选购」

阿里云：

1. 搜索 **轻量应用服务器**
2. 点「立即购买」

> ⚠️ **别买错产品**：
> - 不要买「云虚拟主机」——那是老式空间，跑不了 Docker
> - 不要买「OSS / CDN」——那是存储和加速，不是服务器
> - 不要买「云函数」——那是另一条路线（阶段 2 才用）

---

## 3. 逐项选择（照着选）

| 选项 | 选什么 | 说明 |
|---|---|---|
| **地域** | **中国香港** | 免备案，先跑通流程 |
| **镜像** | 系统镜像 → **Ubuntu 22.04 LTS 64位** | 不要选 Windows、不要选宝塔/应用镜像 |
| **套餐** | **2 核 4G**，系统盘 60GB 以上 | 2G 内存会不够，别省这几十块 |
| **带宽** | 3～5 Mbps，或按流量计费 | 香港套餐通常是「高带宽 + 月流量包」 |
| **购买时长** | **1 个月** | 先试一个月，别一上来买一年 |
| **自动续费** | **关闭** | 避免忘记后自动扣费 |
| **数量** | 1 台 | |

> 💡 **为什么是香港？**
> 大陆服务器绑定域名必须 ICP 备案（2～4 周，个人备案对相册类内容有限制）。
> 香港节点免备案，适合先把整套流程跑通。速度对两个人用完全够。
>
> 💡 **为什么先买 1 个月？**
> 云厂商的「新用户特惠」很便宜，但**续费价通常贵不少**。
> 先花几十块验证整套方案跑得通，确认满意再考虑续更久，避免一次投入打水漂。
>
> 💡 **为什么关自动续费？**
> 不是不续，是**把决定权留在自己手里**。到期前你会收到提醒，到时候再决定。

## 4. 下单支付

1. 勾选同意协议
2. 点「立即购买」
3. 微信 / 支付宝付款
4. 付款成功后，点「进入控制台」

---

## 5. 买完 5 分钟内要做的三件事

### 5.1 记下公网 IP

控制台 → 轻量应用服务器 → 实例列表 → 找到刚买的机器：

- **公网 IP**：形如 `43.xxx.xxx.xxx`，抄下来
- **内网 IP**：不用管
- **登录用户名**：Linux 一般是 `root`（控制台会写）

### 5.2 设置防火墙（只开三个端口）

实例详情 → **防火墙** 标签页：

保留 / 添加这三条：

| 应用类型 | 协议 | 端口 |
|---|---|---|
| SSH | TCP | 22 |
| HTTP | TCP | 80 |
| HTTPS | TCP | 443 |

如果默认有 `3389`（Windows 远程桌面）、`21`（FTP）之类的，**删掉**，用不到。

> 💡 **防火墙就是门禁**。只开必要的门，被扫描和攻击的面就小。
> 8000 端口（Supabase 后台）**绝对不要**加进来，后面用 SSH 隧道访问。

### 5.3 重置登录密码

实例详情 → 右上角「更多」→「重置密码」：

- 设一个**长密码**（12 位以上，大小写 + 数字 + 符号）
- 确认后按提示重启实例
- 把密码记在密码管理器里，**不要发给我、不要发群里**

> 💡 为什么不用默认密码？云服务器默认密码很弱，且可能被全网扫描。
> 重置成强密码是成本最低的安全措施。

## 6. 第一次登录服务器

### Windows

按 `Win + R`，输入 `powershell`，回车，然后：

```powershell
ssh root@你的公网IP
```

第一次连接会问 `Are you sure you want to continue connecting?`，输入 `yes` 回车。

### Mac / Linux

打开「终端」：

```bash
ssh root@你的公网IP
```

然后输入刚才设置的密码（输入时屏幕不显示字符，是正常的），回车。

看到类似这样的提示就成功了：

```
root@VM-0-12-ubuntu:~#
```

> 💡 **SSH 是什么？** 一种加密的远程登录方式。
> 登录后你敲的每条命令，都在这台远在机房的服务器上执行，而不是你自己的电脑。
> 看到命令提示符变了，就说明你「进到服务器里」了。

## 7. 买完先别急着装东西

先做三个检查，确认机器是好的：

```bash
# 1. 看系统版本（应该是 Ubuntu 22.04）
lsb_release -a

# 2. 看内存（应该是 4G 左右）
free -h

# 3. 看磁盘（应该 60G 左右）
df -h
```

然后就可以回到主施工单，从「第 2 步：第一次登录 + 基础安全」继续了。

## 8. 常见疑问

**Q：香港服务器需要备案吗？**
不需要。备案只针对中国大陆境内的服务器。

**Q：香港访问速度会不会很慢？**
对两个人日常使用足够。照片走 HTTPS 加载，通常一两秒内。真正慢的是原来的境外 Supabase（数据要绕更远）。

**Q：能买 2 核 2G 省点钱吗？**
不建议。Supabase 是一整套服务，2G 内存会频繁 OOM（内存不足杀进程），表现就是网站时好时坏。4G 是舒服的起步线。

**Q：能买 1 核 1G 吗？**
不能，跑不起来。

**Q：需要买「带宽」很大吗？**
不需要。你们只有两个人用，3～5 Mbps 足够；香港套餐自带的高带宽 + 流量包更宽松。

**Q：需要买「云硬盘」「快照」「备份」吗？**
先不用。阶段 1 我们用脚本自己做备份，不花额外的钱。以后需要再加。

**Q：能装宝塔面板吗？**
不建议。宝塔会额外占内存、开端口，还多一层要维护的东西。我们直接用命令行 + Docker，更干净，也更能学到东西。

**Q：买完不想要了能退吗？**
国内云厂商一般支持「5 天无理由退款」（以购买页规则为准），但活动机型、特价机可能不支持。买 1 个月就是把这个风险降到最低。

**Q：账号被要求企业认证怎么办？**
个人实名认证即可购买个人用途的轻量服务器，一般不会要求企业认证。遇到提示按页面指引操作。
